Sobre

Desenvolvedor Back-end

Sou desenvolvedor back-end com experiência no desenvolvimento, manutenção e otimização de sistemas internos voltados à melhoria de performance e automação de processos. Tenho foco em resolver problemas reais e entregar soluções que otimizem o trabalho da equipe e tragam mais eficiência para o dia a dia das empresas.

Já atuei em projetos que exigiram desde a automação de tarefas manuais até a estruturação de relatórios personalizados, com base em dados dinâmicos e parâmetros definidos pelos usuários. Trabalhei tanto em desenvolvimento solo, onde fui responsável por todo o ciclo da aplicação, quanto em trabalho em equipe, colaborando na criação e evolução de sistemas completos.

Um dos meus principais diferenciais é a proatividade: quando enfrento um desafio técnico, busco aprender e aplicar soluções rapidamente. Em uma das experiências, investi por conta própria em cursos específicos para modernizar uma estrutura de relatórios desatualizada. O resultado foi a entrega de mais de 10 relatórios funcionais, parametrizados e totalmente integrados ao sistema.

Tenho interesse constante em aprender novas tecnologias, entender as necessidades do negócio e contribuir com sistemas bem estruturados, escaláveis e fáceis de manter. Estou sempre em busca de evoluir como desenvolvedor back-end e entregar soluções que realmente agreguem valor.

Meus Projetos

ESPAIDER

Espaider é um projeto desenvolvido para automatizar um serviço que antes era manual. Ele realiza a migração de relatórios do Excel para o SQL e, com um parâmetro específico, executa uma procedure no SQL que gera relatórios no Report Service.

Relatórios Espaider

O Relatórios Espaider foi um projeto desenvolvido para complementar o funcionamento do Espaider. Originalmente, os relatórios eram criados no Crystal Reports, mas foram migrados para o SQL Server Reporting Services (SSRS) para melhor integração e funcionalidade.

StrongFuel

O StrongFUEL foi um projeto de e-commerce que desenvolvi na faculdade, utilizando PHP e MySQL. Ele possui banco de dados integrado, permitindo o uso do carrinho de compras, uma página principal com os produtos e uma página de gestão onde é possível adicionar, editar ou remover itens da loja.

JARI e GESTÃO

A Ficha de Inscrição JARI foi um projeto desenvolvido para o processo de seleção de representantes da comunidade na JARI da Prefeitura Municipal de São Paulo. Esse foi o meu primeiro projeto e tinha como objetivo principal coletar dados dos candidatos por meio de um formulário com diversos campos pessoais.


Além disso, o sistema incluía uma página de Gestão, acessível apenas por pessoas autorizadas, onde era possível visualizar todas as informações enviadas.

Desafios Espaider


• Migrar planilhas do Excel para o SQL Server, garantindo que as colunas da planilha fossem enviadas corretamente para as colunas com o mesmo nome no banco, mesmo quando a planilha viesse com formatos diferentes.


• Ao finalizar o projeto, enfrentei um problema onde os relatórios funcionavam apenas para usuários conectados ao nosso servidor interno.


• A solução foi criar um projeto em ASPX conectado ao Espaider, que fazia a chamada dos relatórios e passava o parâmetro necessário, garantindo que qualquer pessoa com acesso ao sistema pudesse visualizar os relatórios corretamente.


Tecnologias utilizadas:


• C# • .NET • ASPX • SQL Server • HTML • CSS • JavaScript • BootStrap

Desafios Relatorio Espaider


• O primeiro desafio foi lidar com o Crystal Reports, já que nunca tinha trabalhado com ele antes. Além disso, os relatórios estavam em uma máquina remota, o que dificultava o acesso e a compreensão do funcionamento.


• O segundo desafio foi migrar os relatórios para o SSRS (SQL Server Reporting Services). Para isso, precisei procurar e até pagar cursos para aprender como utilizar o SSRS e fazer a migração corretamente do Crystal Reports para o novo sistema.

Desafios Ficha de Inscrição JARI



• O maior desafio foi não saber nada de programação. Eu já havia estudado na faculdade para criar códigos voltados para matemática e feito cursos de lógica de programação, mas nunca tinha programado para valer.


• Como eu e meu colega de estágio estávamos aprendendo juntos, tivemos que estudar bastante durante um mês sobre todas as tecnologias envolvidas.


• O projeto foi um desafio após o outro, como formatar campos, conectar o front-end com o back-end, validar dados como CPF e e-mail, além de aprender a conectar o back-end ao banco de dados SQL Server.


• Outro desafio foi impedir que o usuário manipulasse a URL para garantir a integridade das informações.


• No final, a parte de Gestão foi mais simples, conectamos com o banco de dados e criamos a tabela para visualizar as informações da inscrição.


• Apesar de muitos erros simples ao longo do processo, conseguimos corrigir tudo e apresentar o projeto funcionando.

Tecnologias utilizadas


• C# • .NET • SQL Server • HTML • CSS • JavaScript • Bootstrap
